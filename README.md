tm control panel is a Chromium extension that takes the repetitive clicking and clutter out of choosing seats on Ticketmaster. Click the tm icon on any Ticketmaster page and a small rounded panel opens with a big power switch for the whole extension, followed by five options that are all on by default.

Auto Clicks

Auto Add Multi-Offer Seats: on events with several price offers, it presses Add for every seat you pick, so you don't have to click it one by one. The button can stay invisible too.
No Startup Infos: closes the info pop-ups that appear when a page or seat map loads.
Auto Accepts Accessibility Agreements: ticks the agreement checkbox first, waits a moment, then presses Continue.

Hide From Page

No Discover More: hides the Discover More button in the side panel.
No Verified Resale Seats: hides Verified Resale listings from the side panel list.

How to use it

Load the extension and refresh any Ticketmaster tabs that were already open.
Click the tm icon to open the panel. Press Esc, click outside it, or click the icon again to close it.
Use the power switch to turn everything off at once. The options go grey and stop working, and your choices are kept.
Toggle single options as you like. Changes apply instantly in every tab and window.
The info button explains each option. The gear sets click speed (Fast, Normal, Slow), whether the auto-clicked Add button stays hidden, and a reset to defaults.

It runs on Ticketmaster's .com, .co.uk, .ie, .ca, .com.au and .co.nz sites. On other sites, the icon opens a plain popup version of the same panel.
